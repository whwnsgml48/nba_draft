사용법

1. 기본 — 빠른 기록 모드

낙찰된 것만 찍는 모드다. 한 입력창에서 선수 → 팀 → 금액 세 단계.

웸비 ⏎   선수   한글 별칭 · 영문 · 초성(ㅇㅂ) · SGA/KD
병 ⏎     팀     접두사 1~2자면 유일해진다
87 ⏎    낙찰

후보가 여럿이면 1~8 로 고른다. ⏎ 는 항상 첫 후보. 빈 입력에서 Backspace 는 한 단계 뒤로, Esc 는 처음으로.

DB에 없는 선수는 검색 결과에 임시 등재가 뜬다. 그대로 ⏎.

2. 라이브 호가 모드 Tab

호가 경쟁을 실시간으로 따라갈 때만 쓴다. 10초 타이머는 이 모드에만 있다.

요키치 ⏎  지명 — 지명자 이름으로 자동 $1 입찰
병34 ⏎    병욱 $34 · 타이머 리셋
윤41 ⏎    윤범 $41
⏎        (빈 입력) 최고가로 낙찰
Esc      지명 취소 — 낙찰 없음

팀 접두사에 금액을 붙여 쓴다 — 한글에 숫자가 없어 병34 로도 통한다. 지명하면 좌측에 다음 동작 3줄이 뜨고, 타이핑하는 대로 파싱 결과를 되비춘다.

타이머가 0이 되어도 자동 낙찰하지 않는다. 규칙은 10초 자동 마감이지만 오낙찰이 무입찰보다 비싸다. "낙찰 대기"를 띄우고 사람의 ⏎ 를 기다린다.

3. 실수 되돌리기

두 가지가 따로 있다.

  • Ctrl/⌘+Z — 시간 되돌리기. 방금 한 일을 무르며 횟수 제한 없다. Ctrl/⌘+Shift+Z 로 다시 실행.
  • 로그 행의 [취소] — 개별 철회. 한참 전 낙찰 하나만 지운다. 예산·순번이 자동 복구된다.

전체 초기화도 Ctrl/⌘+Z 로 되돌릴 수 있다.

4. 지명 순서

순번 로테이션이다 (직전 낙찰자 지명이 아니다). 상단에 다음 4명이 뜨고, 로스터 9명을 다 채운 팀과 이름 없는 팀은 자동으로 건너뛴다.

스네이크를 켜면 라운드마다 순서가 뒤집힌다 (1→14, 14→1, …). 양 끝 팀이 연속 두 번 지명한다. 리그 규칙에 맞춰 팀 설정에서 켜고 끈다.

당일 추첨 결과는 팀 설정 → 지명 순서 에 접두사만 순서대로 띄어 쓴다.

병 준 진 경 원 윤 단 지 두 수 철 정 강 완

진행 중에 바꿔도 이미 낙찰된 건은 영향받지 않는다.

5. 툴이 강제하는 것

  • 최대입찰가 = 잔액 − (남은 슬롯 − 1). 초과 입찰은 거부되고 이유를 말한다.
  • 로스터 9명 초과, $0 이하, 중복 낙찰 거부.
  • 우상단 장부 배너는 기록 정확성만 센다. 🔴 가 뜨면 세션 파일이 손상된 것이다.
  • 포지션은 보여주기만 한다 — 각 팀 책임이고 포기도 전략이므로 낙찰을 막지 않는다.

6. 성적 카드 읽기

리그 13캣 순서를 그대로 따른다. 초점 선수(후보 1위 또는 확정한 선수)가 항상 보인다.

  • OREB 공격 리바운드 · A/T 어시스트÷턴오버 · DD 시즌 더블더블 추정
  • TOV 는 낮을수록 좋은 항목이라 붉게 쓴다.
  • — 는 산출 불가다. A/T 는 TOV가 0이면 나눌 수 없고, 2026 신인은 NBA 실적이 없다.

카드 아래 출처 표기의 뜻:

  • 2시즌 GP가중 혼합 — 2025-26과 2024-25를 출장 경기수로 섞었다 (최근 시즌 가중)
  • 2024-25 실적 (2025-26 결장) — 지난 시즌을 통째로 쉰 선수 (부상 복귀조)
  • NBA 실적 없음 — 2026 드래프트 신인

7. 저장과 내보내기

  • 모든 변경은 브라우저에 자동 저장된다. 새로고침·크래시로 잃지 않는다.
  • 세션 저장 / 불러오기 — 기기를 옮기거나 백업할 때.
  • 결과 CSV — 작년 기록과 같은 형식. 리그 이력 보관용.

이 파일은 네트워크를 쓰지 않는다. 비행기 모드에서도 전부 동작한다.

불변식

I1~I4 = 장부 정확성. 진행자의 책임 범위이고 낙찰 단계에서 이미 차단된다. 여기서 걸리면 세션 파일이 손으로 수정됐거나 외부에서 불러온 것이다.
I5 = 포지션, 정보 등급. 포지션 관리는 각 팀 책임이고 포기도 전략이다. 보여주기만 하며 배너 색을 바꾸지 않고 낙찰도 막지 않는다 — 진행자가 조치할 일이 아니다.
