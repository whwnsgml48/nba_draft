# 옥션 진행 콘솔 (커미셔너용)

14팀 · $200 · 로스터 9명 · H2H 13캣 리그의 **오프라인 옥션 진행 장부**.
계획·진단·일정은 [RENEWAL.md](RENEWAL.md).

## 쓰는 법

`console.html` 을 브라우저로 열면 끝이다. 설치·서버·네트워크 없다.

**처음 열면 사용법이 뜬다.** 이후에는 `?` 나 상단 `사용법 ?` 버튼으로 언제든 다시 열 수 있다 —
아래 내용은 전부 툴 안에도 들어 있으니 이 파일 없이 넘겨도 된다.

한 입력창에서 **선수 → 팀 → 금액** 3단계. 마우스는 안 쓴다.

```
웸비 ⏎        선수 확정   (한글 별칭 · 영문 · 초성 · SGA/KD 같은 이니셜)
병 ⏎          팀 확정     (접두 1~2자면 유일해진다)
87 ⏎          낙찰
```

| 키 | 동작 |
|---|---|
| `1`~`8` | 후보 n번째 선택 |
| `Enter` | 첫 후보 선택 / 금액 확정 |
| `Backspace` (빈 입력) | 한 단계 뒤로 |
| `Esc` | 입력 초기화 |
| `Ctrl/Cmd+Z` | 되돌리기 (무제한) |
| `Ctrl/Cmd+Shift+Z` | 다시 실행 |
| `Tab` | 빠른 기록 ↔ 라이브 호가 모드 |

- 모든 변경은 **localStorage 자동 저장**. 새로고침·크래시로 안 잃는다.
- 로그의 `[취소]`는 개별 철회, `Ctrl+Z`는 시간 되돌리기다. 둘 다 있다.
- DB에 없는 선수는 검색 결과에서 **임시 등재**로 바로 넣는다.
- 최대입찰가는 리그 규칙 `잔액 − (남은 슬롯 − 1)`을 강제한다. 초과·$0·10번째 선수는 거부된다.
- **지명은 순번 로테이션**이다(2026-09-01 변경). 상단에 다음 4명이 뜨고, 만석 팀과 이름이
  빈 팀은 자동으로 건너뛴다. 순서는 `data/teams.json` 배열 순이다.
- 우상단 **장부 배너**(`장부 ✅ 4/4`)를 클릭하면 상세가 열린다. 배너는 **진행자 책임 범위인
  장부 정확성만** 센다(I1~I4). 포지션(I5)은 `· 포지션 1건` 으로 색 없이 붙는다 — 각 팀
  책임이고 포기도 전략이라 진행자가 조치할 일이 아니다.
- 팀 카드에 부족 포지션(`C 없음`)·`예산 소진` 플래그가 붙는다. 낙찰은 어떤 경우에도 막지 않는다.
- 입력창 아래 **13캣 성적 카드**가 항상 초점 선수를 보여준다 — 후보 1위든, 확정한 선수든.
  PTS REB OREB AST STL BLK TOV 3PM FG% 3P% FT% A/T DD MPG. TOV 는 빨갛게(낮을수록 좋은 항목).
- 14팀 시드는 `data/teams.json` 이 정본이다. 화면 `팀 설정`에서도 고칠 수 있고, 이름이 빈 팀에는 낙찰이 거부된다.

## 라이브 호가 모드 (`Tab`)

**기본은 빠른 기록 모드이고, 타이머는 라이브 모드에만 있다.** 우상단 `모드: 빠른 기록`
버튼을 누르거나 `Tab` 을 치면 바뀐다. 전환하면 좌측에 `지명 대기 ⏱ 10s` 패널이 나타나고,
선수를 지명하는 순간 카운트다운이 시작된다.

```
요키치 ⏎     지명 — 지명자 이름으로 자동 $1 입찰이 걸린다 (리그 규칙)
병34 ⏎       병욱 $34 입찰 · 10초 타이머 리셋
윤41 ⏎       윤범 $41
⏎            (빈 입력) 최고가로 낙찰
Esc          지명 취소 — 낙찰 없음
```

지명하면 좌측에 **다음 동작 세 줄**이 뜬다. 무엇을 눌러야 하는지 화면이 직접 말한다.

```
[팀+금액 ⏎]  입찰   예: 병34 — 팀 접두사에 금액을 붙여 쓴다
[빈 입력 ⏎]  낙찰   병욱 에게 $34 확정          ← 대상과 금액을 항상 명시
[Esc]        취소   낙찰 없이 지명 철회
```

타이핑하면 그 줄이 파싱 결과를 되비춘다 — `병3` 을 치면 `병욱 $3 로 입찰`, 틀리면
`현재가 $34 보다 높아야 한다` 처럼 이유가 붉게 뜬다. 유효한 쪽 줄이 강조된다.

10초 타이머는 3·2·1초에 비프, 0초에 낮은 톤을 낸다. **0초가 되어도 자동 낙찰하지 않는다** —
"낙찰 대기"를 띄우고 진행자의 Enter 를 기다린다. 오낙찰이 무입찰보다 비싸다.
입찰 이력은 낙찰 레코드에 함께 저장되므로 재시작해도 남는다.

## 지명 순서

당일 추첨 결과를 `팀 설정 → 지명 순서` 에 **접두사만 순서대로** 띄어 쓴다.

```
병 준 진 경 원 윤 단 지 두 수 철 정 강 완
```

모호하면(`지` 가 지원·지훈 둘) 후보를 보여주고 거부한다. ↑↓ 미세 조정과 "현재 지명 위치"
지정도 있다. 진행 중에 바꿔도 이미 낙찰된 건은 영향받지 않는다.

## 빌드

```
python3 build_db.py     # 선수 DB → data/players.min.json  (의존성 0)
python3 embed.py        # + console.src.html → console.html (단일 파일)
```

`console.src.html` 이 원본이다. `console.html` 은 생성물이니 직접 고치지 말 것.

데이터 출처는 전부 `../nba_fantasy_auction_2026` 의 로컬 파일이다 (BBRef 2시즌 · 실측 혼합 ·
시장가 · 작년 옥션 결과). 재수집·스크래핑 없다.

## 범위와 정보 경계

이 툴은 **리그 전체 사실 기록**이다 — 누가 얼마에 갔나. 밸류 판단은 하지 않는다.

`console.html` 은 커미셔너에게 파일째로 넘어갈 수 있고 화면이 테이블에서 보인다.
그래서 **개인 평가·목표가는 임베드 데이터에 담지 않는다.** 화면에서 감추는 게 아니라
`build_db.py` 단계에서 버리고, 유출 0건을 인수 조건으로 검사한다.
정렬 가중치처럼 금액이 역산되는 경로도 서수로 치환했다.
